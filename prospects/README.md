# Nigeria & Kenya Tech Prospects (Under 100 Employees)

Cold-outreach prospect list of **software companies, tech agencies, and startups** in Nigeria and Kenya with fewer than ~100 employees. Contacts were gathered from public company websites, careers pages, and public company profiles (not purchased lead databases).

## File

- [`nigeria-kenya-tech-prospects.csv`](./nigeria-kenya-tech-prospects.csv) — importable spreadsheet

## Columns

| Column | Meaning |
| --- | --- |
| `company_name` | Legal / trading name |
| `country` | Nigeria or Kenya |
| `city_location` | City / office area when known |
| `estimated_employees` | Public signals (site “team size”, LinkedIn headcount, TechBehemoths bands). All targets are intended **&lt; 100**. |
| `type` | Software company, digital agency, studio, ICT, etc. |
| `contact_email` | Public email (general, founder, sales, partnerships, HR, or careers) |
| `contact_role_or_type` | Best-guess inbox purpose |
| `website` | Primary site |
| `short_description` | What they do / services |
| `source_notes` | Where the email was found |

## Coverage (unique companies)

- **Nigeria (~20):** Lagos, Abuja, Port Harcourt — software studios, digital agencies, ICT firms
- **Kenya (~16):** Mostly Nairobi — software studios, agencies, ERP/product firms

Some companies appear on more than one row when they publish multiple useful inboxes (e.g. `hello@` + `partnerships@`, or `info@` + `careers@`).

## How contacts were found

1. Directory / search discovery (TechBehemoths team-size filters, Google, company sites)
2. Open each company website (home, contact, about, careers)
3. Prefer **CEO/founder/general**, then **sales/partnerships**, then **HR/careers**
4. Prefer firms that publicly signal small/mid size (e.g. 2–9, 10–49, “small studio”, named team of &lt;10)

## Excluded on purpose

- Large / household names (e.g. major unicorns and telcos)
- Firms clearly signaling **100+** employees
- Contacts that only appear behind paid lead-list paywalls with no public site confirmation

## Before you email

1. Re-check the live website — small companies change domains and inboxes often
2. Prefer personalized outreach; many inboxes are shared (`hello@` / `info@`)
3. Comply with applicable email marketing / anti-spam rules in your jurisdiction and theirs
4. Treat `estimated_employees` as approximate; re-verify on LinkedIn before scoring ICP fit
